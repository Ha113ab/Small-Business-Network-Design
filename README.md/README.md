# Small Business Network Design

Rebuilt small business network design and security architecture document (September 2025), not a Packet Tracer simulation. No .pkt file is included, because none exists.

## What it covers

- Small business network design and security architecture
- A Packet Tracer build guide for rebuilding the topology in Packet Tracer
- A topology diagram
- Device configuration files for an edge router, a core switch, and an access switch

## Files

All project files are in `small-business-network-design/`:

- `README.md` - project README in that folder
- `Small_Business_Network_Design_Security_Architecture.pdf` - design and security architecture document
- `topology.png` - topology diagram
- `PACKET_TRACER_BUILD_GUIDE.md` - Packet Tracer build guide
- `configs/edge-router.txt`, `configs/core-switch.txt`, `configs/access-switch.txt` - device configurations

## How to read it

Start with `small-business-network-design/README.md`, then the architecture PDF and the build guide.
